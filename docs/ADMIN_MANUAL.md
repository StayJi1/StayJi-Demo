# StayJi Admin Manual

## Dashboard

Use the admin dashboard for city-scoped property moderation, users, owners, leads, reviews, analytics, move-ins, and notifications.

## Filters

Dashboard filters support search, city, owner, property type, approval status, active status, occupancy, and date range. Filters update property tables and analytics.

## Property Moderation

Review listings, verify or reject properties, activate/deactivate records, inspect owner details, and use bulk table actions for selected rows.

## Payment Requests

Move-in requests show pending, suspicious, rejected, and approved reward claims. Approve rewards only after payment proof and owner confirmation are present.

## Reviews And Messages

Moderate reviews, inspect complaints, communicate with owners, and use notification redirects to return to the related workflow.
