# StayJi Super Admin Manual

## Scope

Super Admin has global authority over admins, cities, dummy/live inventory, permissions, monetization, SEO, audit logs, moderation, and analytics.

## City Governance

Manage state and city records, assign City Admins, define operational scope, and control dummy visibility for phased rollout.

## Dummy And Live Controls

Use the dummy transition tools to show demo inventory, hide demo inventory, or mark selected city inventory live. Demo properties are labeled for transparency until official launch.

## Account Governance

Create regional admins, owners, and user accounts. Super Admin can override admin scope, reset passwords through the secure workflow, and audit major account changes.

## Monetization

Commission and reward rules are tracked through property commission config and verified move-in records. Reward approval depends on payment proof, owner confirmation, property verification, and admin approval.
