# StayJi Owner Manual

## Registration

Owners must choose a Super Admin managed state and city during signup. The account appears under the matching City Admin dashboard and needs approval before listings can go live.

## Property Management

Create listings with locality, map coordinates, photos, pricing, room sharing blocks, vacancy counts, food options, amenities, and owner agreements. Use Add Custom Amenity for property-specific features like private fridge, study table, rooftop access, or biometric entry.

## Sharing Configuration

Add or delete room sharing blocks for single, double, triple, four sharing, or custom types. Each block supports occupancy, pricing, vacancy, attached/shared bathroom, balcony, AC, furnishing, food preference, and gender.

## Leads And Messages

Track inquiries, visits, shortlists, converted leads, and private admin messages from the owner dashboard.

## Move-In Confirmation

When a user submits move-in proof, confirm Tenant joined successfully only after the tenant actually joins. Admin reward approval is blocked until this confirmation is done.
